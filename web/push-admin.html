Once FCM is added, FCM tokens will be stored in Firestore (fcmTokens/{uid}), enabling server-side audience targeting and the compose tab.

How to Enable Remote Push (Android first)

1

Add firebase_messaging to pubspec.yaml

Open pubspec.yaml and add under dependencies:

  firebase_messaging: ^15.0.0   # check pub.dev for latest

Then run flutter pub get. The plugin auto-registers the FCM background message handler on Android.

2

Request permission and save the FCM token to Firestore

In lib/services/local_notifier.dart (or a new push_service.dart), after existing notification setup:

final messaging = FirebaseMessaging.instance;
await messaging.requestPermission();
final token = await messaging.getToken();
if (token != null) {
  await FirebaseFirestore.instance
    .collection('fcmTokens')
    .doc(FirebaseAuth.instance.currentUser!.uid)
    .set({
      'token': token,
      'platform': Platform.isAndroid ? 'android' : 'ios',
      'updatedAt': FieldValue.serverTimestamp(),
    }, SetOptions(merge: true));
}

The fcmTokens/{uid} collection becomes the push audience list.

3

Add a Firestore security rule for fcmTokens

In firestore.rules:

match /fcmTokens/{uid} {
  allow read:  if false;              // server-only reads
  allow write: if request.auth.uid == uid;
}
4

Create the push-poll GitHub Actions workflow

Mirror the video-poker-game pattern: a Node.js script reads queued campaigns from pushCampaigns in Firestore, fans out to FCM via the Firebase Admin SDK using a service-account key stored as a GitHub Actions secret, then marks campaigns as delivered.

File: .github/workflows/push-poll.yml — runs every 5 minutes:

on:
  schedule:
    - cron: '*/5 * * * *'
  workflow_dispatch:
5

(Later) iOS — APNs entitlement

Requires a paid Apple Developer account.
① Enable Push Notifications in Xcode → Signing & Capabilities.
② Create an APNs Auth Key in the Apple Developer portal.
③ Upload it to Firebase Console → Project Settings → Cloud Messaging → iOS app.
④ The same firebase_messaging plugin handles iOS automatically.
